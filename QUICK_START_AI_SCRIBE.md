# 🚀 Quick Start: MindShift AI Scribe

## 🎯 What is it?

The MindShift AI Scribe transforms your clinical sessions into comprehensive, billing-ready progress notes automatically. Just record your session, and let AI handle the documentation.

## 📍 How to Access

1. **Log in** to MindShift+
2. Look for the **Admin** section in the sidebar
3. Click **🎙️ AI Scribe**

## 🎬 3-Step Workflow

### Step 1: Setup (2 minutes)
```
📋 Enter patient information
   • Patient ID
   • Date of Service
   • Your name

🏥 Configure session
   • Session Type (Follow-up, Initial, etc.)
   • Modality (Telehealth/In-Person)
   • Duration

🧠 Select specialty
   • Psychiatry
   • Psychology
   • Primary Care
   • Pediatrics

📝 Add clinical context (optional)

✅ Click "Start Recording Session"
```

### Step 2: Record (Session Duration)
```
🎙️ Click "Start Recording"

⏸️ Use Pause/Resume as needed

⏱️ Monitor timer

📝 View live transcript

✅ Click "Complete Visit & Generate Note"
```

### Step 3: Review & Export (1 minute)
```
📄 Review AI-generated note

📊 Check quality score

📋 Copy to clipboard
   OR
⬇️ Download as text file
   OR
🏥 Push to EHR

🔄 Start new session
```

## ⏱️ Total Time: ~3 minutes of admin work per session!

## ❓ FAQ

### Q: Can I edit the generated note?
**A:** Currently, you can copy it and edit in your preferred editor. Future versions will have inline editing.

### Q: Is the audio saved?
**A:** Audio is processed in real-time and not permanently stored (HIPAA compliant).

### Q: What if I lose connection during recording?
**A:** The recording continues locally. Reconnect to complete the session.

### Q: Can I use this for group therapy?
**A:** Yes! Just note multiple participants in the clinical context field.

### Q: How accurate is the transcription?
**A:** Current version uses simulated transcription. Real API integration coming soon for 95%+ accuracy.

### Q: Can I customize the note format?
**A:** The full AI Scribe project includes template customization. Contact dev team for integration.

## 🆘 Troubleshooting

### Can't see AI Scribe in menu?
- ✅ Verify you're logged in with an admin email
- ✅ Check the Admin section of the sidebar
- ✅ Refresh the page

### Recording not starting?
- ✅ Allow microphone permissions in browser
- ✅ Check microphone is connected
- ✅ Try a different browser (Chrome recommended)

### Note not generating?
- ✅ Ensure you recorded for at least 10 seconds
- ✅ Check internet connection
- ✅ Try again or contact support
